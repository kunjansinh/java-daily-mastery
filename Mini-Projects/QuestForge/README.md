\# ⚔️ QuestForge



QuestForge is a text-based RPG built in Java.



The project is designed to improve Java programming skills by gradually

introducing real programming concepts through a playable mini-game.



\## 🎮 Current Version



\*\*Version:\*\* 0.1  

\*\*Status:\*\* In Development



\## 🧙 Core Features



\- Create a player character

\- Fight enemies

\- Manage health

\- Attack enemies

\- Earn experience

\- Level up

\- Earn coins

\- Collect items

\- Explore the game world



\## 🛠️ Java Concepts



The project will gradually introduce:



\- Classes and Objects

\- Constructors

\- Encapsulation

\- Inheritance

\- Interfaces

\- Polymorphism

\- Arrays and Collections

\- Enums

\- Exception Handling

\- File Handling

\- Generics

\- Lambda Expressions

\- Streams

\- Unit Testing
